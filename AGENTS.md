# AGENTS.md: instructions for the coding agent (opencode)

This repo is a take-home assignment (DoCoDeGo SDE intern task 002). The owner must understand and
explain EVERY line, so prefer simple, readable code over clever code. Read `README.md` first: it
is the specification.

## Current state

A complete, tested solution already exists. Your job is to REVIEW, VERIFY and make small safe
improvements. Do NOT rewrite working code or change the architecture.

## Hard rules (a violation can fail the assignment)

1. NEVER edit `api/test/helpers.ts`, `api/test/apply-migrations.ts`, `api/test/env.d.ts`,
   `api/test/homes.test.ts`, `api/test/bills.test.ts`, `api/test/payments.test.ts`.
   New tests go in NEW files in `api/test/`.
2. No `any` (also no `as any`, no `// @ts-ignore`). Strict TypeScript on both sides.
3. Every error response is JSON `{ "error": "message" }`, including 404 and 500.
4. Money is whole integer cents. Never decimals for storage or API.
5. Schema lives only in `api/migrations/*.sql`, with at least 3 NAMED constraints.
   Do not edit `0001_init.sql` after review sign-off; add `0002_*.sql` for changes.
6. Do not add dependencies unless truly needed. Do not add features beyond the README.
7. Do not hand-edit `web/src/routeTree.gen.ts` (generated by `pnpm build` / `pnpm dev`).

## The gate (must all pass before you finish)

```
pnpm install && pnpm check && pnpm typecheck && pnpm test && pnpm build
```
Use `pnpm check:fix` for Biome formatting. If you change `api/wrangler.jsonc`, run
`pnpm --filter bill-splitter-api cf-typegen`.
